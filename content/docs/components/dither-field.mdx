Move the pointer over it: a soft spot brightens under the cursor (and under a finger on touch screens). Turn it off with `interactive={false}`; it is always off under reduced motion.

## Installation

```bash
npx shadcn@latest add https://ditherui.com/r/dither-field.json
```

## Usage

```tsx
import { DitherField } from "@/components/ui/dither-field";

<DitherField style={{ height: 320 }}>
  <h1>Hello</h1>
</DitherField>
```

## Fields

`noise` (`scale`), `radial` (`x`, `y`, `radius`) and `linear` (`angle` in degrees), tuned with `params`.

<DitherFieldFieldsDemo />

```tsx
<DitherField field="noise" params={{ scale: 6 }} />
<DitherField field="radial" params={{ radius: 0.6 }} />
<DitherField field="linear" params={{ angle: 30 }} />
```

## Tokens

Set tokens once with `DitherProvider`; any prop overrides them for one component. Here the provider sets `gameboy`, and the right field overrides it with `amber` and `bayer8`.

<DitherFieldProviderDemo />

```tsx
import { DitherProvider } from "@/lib/ditherui/provider";

<DitherProvider palette="gameboy" cell={4}>
  <DitherField />
  <DitherField palette="amber" pattern="bayer8" />
</DitherProvider>
```
