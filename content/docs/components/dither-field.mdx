## Usage

```tsx
import { DitherField } from "@/components/ui/dither-field";

<DitherField style={{ height: 320 }}>
  <h1>Hello</h1>
</DitherField>
```

## Fields

`noise` (`scale`), `radial` (`x`, `y`, `radius`) and `linear` (`angle` in degrees), tuned with `params`.

<Preview>
  <DitherFieldFieldsDemo />
</Preview>

```tsx
<DitherField field="noise" params={{ scale: 6 }} />
<DitherField field="radial" params={{ radius: 0.6 }} />
<DitherField field="linear" params={{ angle: 30 }} />
```

## ASCII

Set `mode="ascii"` to draw glyphs instead of pixels. `glyphs` takes a ramp name (`standard`, `blocks`, `binary`, `katakana`) or your own string, ordered background → foreground. With 3–4 colours, glyphs are tinted by brightness band.

<Preview>
  <DitherFieldAsciiDemo />
</Preview>

```tsx
<DitherField mode="ascii" />
<DitherField mode="ascii" glyphs="blocks" cell={12} palette="cga" />
```

## Tokens

Set tokens once with `DitherProvider`; any prop overrides them for one component. Here the provider sets `gameboy`, and the right field overrides it with `amber` and `bayer8`.

<Preview>
  <DitherFieldProviderDemo />
</Preview>

```tsx
import { DitherProvider } from "@/lib/dotgrain/provider";

<DitherProvider palette="gameboy" cell={4}>
  <DitherField />
  <DitherField palette="amber" pattern="bayer8" />
</DitherProvider>
```

## Patterns

Ordered patterns run on the GPU. `blueNoise` is generated the first time it is used. The error-diffusion patterns `atkinson` and `floyd` only apply to images; on a field they fall back to `bayer4` with a warning in development.

</Preview>

## Fallbacks

- **No WebGL2:** the field renders through a Canvas2D path in both modes, matching the GPU output. In development, add `?cpu=1` to any URL to force it.
- **Context loss:** while the GPU context is lost, views draw on the CPU; once it is restored, programs and textures rebuild and every view redraws without remounting.
- **Reduced motion:** with `prefers-reduced-motion: reduce`, the field draws one static frame with no animation and no cursor spot.

## Accessibility and performance

- The canvas is `aria-hidden`; children stay real DOM text. Pass `label` only when the field itself conveys meaning, which announces it as one image.
- Animation runs on one shared requestAnimationFrame loop, pauses offscreen and in hidden tabs, and freezes to a still frame under reduced motion. `radial` and `linear` fields only redraw when something changes.
- The field renders at quantized resolution (size ÷ `cell`) and is upscaled with crisp pixels; device pixel ratio is capped at 2.
