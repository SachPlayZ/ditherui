## Installation

```bash
npx shadcn@latest add https://ditherui.com/r/dither-field.json
```

## Usage

```tsx
import { DitherField } from "@/components/ui/dither-field";

<DitherField style={{ height: 320 }}>
  <h1>Hello</h1>
</DitherField>
```

## Tokens

Set tokens once with `DitherProvider`; any prop overrides them for one component. Here the provider sets `gameboy`, and the right field overrides it with `amber` and `bayer8`.

<DitherFieldProviderDemo />

```tsx
import { DitherProvider } from "@/lib/ditherui/provider";

<DitherProvider palette="gameboy" cell={4}>
  <DitherField />
  <DitherField palette="amber" pattern="bayer8" />
</DitherProvider>
```
